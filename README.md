# The Last Checkout

**The Last Checkout** is a third-person puzzle game set in a messy hotel room. Tidy the room, collect the door code and check out before time runs out!

## Game Concept
You're about to check out of your hotel room, but the room is a mess and the door is locked. Put everything back in its place to reveal the 5-digit door code, one digit per task. There are no written instructions: **glowing objects** show what to do next, and **see-through "ghost" copies** show where things belong. Finish all 5 tasks, unlock the door and walk out before the 5-minute checkout timer ends.

## Puzzle Tasks
Tasks must be completed in order. Each finished task makes the next object glow.

1. **The Flower Pot**
   * Pick up the glowing flower pot with `E`
   * Drop it on its ghost by the window
2. **The TV Remote**
   * Pick up the remote from the couch
   * Place it on its ghost on the TV stand
3. **The Painting**
   * The painting above the couch hangs upside-down
   * Press `E` to rotate it until it matches its ghost
4. **The TV**
   * The TV hangs crooked on the wall
   * Rotate it with `E` until it matches its ghost, and the screen lights up
5. **The Checkout Routine**
   * Follow the glow: close the curtains → turn off the music → turn off the TV
6. **The Door**
   * Enter the 5-digit code on the keypad and press `Enter`
   * Walk out into the hallway to check out

## Win & Lose
* **Win:** complete all 5 tasks, unlock the door and exit the room
* **Lose:** the 5-minute timer runs out, **or** you enter 3 wrong door codes
* Progress is always shown on screen: `Puzzle Progress: x / 5`

## Controls
**Movement**
* `W` `A` `S` `D`: move
* `Mouse`: look around
* `Space`: jump
* `Shift`: sprint

**Interaction**
* `E`: pick up / put down / rotate / switch off
* `0–9` + `Enter`: type the door code
* `Backspace`: delete a digit

## Tips
* Only the glowing object can be used, so look for the glow when you're stuck
* Match objects to their ghosts
* Keep an eye on the timer in the top-right corner
* Be careful at the door: you only get 3 tries!
